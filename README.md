# ArenaFit Academia

Projeto de desenvolvimento web realizado para a disciplina de **Design para Web II**, com o objetivo de criar um site institucional para uma academia fictícia, utilizando HTML5 e CSS3.

O ArenaFit apresenta informações sobre a academia, suas modalidades, planos disponíveis, estrutura física e horários de funcionamento. O site também conta com um formulário para que novos alunos possam demonstrar interesse em realizar uma matrícula.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas e organização do conteúdo.
- **CSS3:** estilização dos elementos, cores, layouts e responsividade.
- **Google Fonts:** utilização da fonte Montserrat na identidade visual do site.
- **Git e GitHub:** versionamento e gerenciamento das alterações do projeto.

## Funcionalidades

O site é dividido em cinco páginas principais:

### Página inicial
Apresenta a academia, seus diferenciais, uma promoção de matrícula e depoimentos de alunos, além de links que direcionam o visitante para as demais páginas.

### Modalidades
Exibe informações sobre as atividades oferecidas pela academia, incluindo:

- Musculação
- Treinamento funcional
- Pilates
- Personal Trainer

Cada modalidade possui uma descrição, seus principais benefícios e horários disponíveis.

### Planos
Apresenta os planos mensal, trimestral, semestral e anual, com valores e benefícios para comparação.

### Estrutura
Disponibiliza informações sobre as instalações da academia, equipamentos, professores, horários das aulas coletivas e funcionamento.

### Matrícula
Contém um formulário para o preenchimento de dados pessoais, escolha do plano, modalidade, horário de preferência e observações sobre os objetivos do aluno.

O formulário utiliza campos HTML com validação básica pelo navegador. Atualmente, não possui integração com banco de dados ou sistema de envio das informações.

## Como executar o projeto

1. Clone o repositório utilizando o comando:

   ```bash
   git clone https://github.com/viniciuscorreagoncalves-cyber/ArenaFit.git
   ```

2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `Html/index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server do VS Code.

Não é necessária a instalação de dependências ou de um servidor de backend para visualizar as páginas.

## Organização e estilização

O projeto utiliza um arquivo CSS compartilhado entre as páginas, permitindo manter um padrão visual.

A identidade visual é composta principalmente por tons de laranja, azul, preto e cinza, com elementos como cartões, botões, tabelas e efeitos de interação.

Também foram utilizadas media queries para adaptar partes do layout a diferentes tamanhos de tela.

- Construção de layouts responsivos.
- Criação de formulários e tabelas.
