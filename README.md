# Fitcode Academia

Site institucional da academia **Fitcode**, desenvolvido para a disciplina de **Design para Web II**.

O projeto apresenta a academia, suas modalidades, planos e estrutura, e permite que o visitante preencha um formulário de matrícula.

## Páginas

| Página | Arquivo | Conteúdo |
|---|---|---|
| Início | `Html/index.html` | Apresentação, promoção, diferenciais, depoimentos de alunos |
| Modalidades | `Html/modalidades.html` | Musculação, Treinamento Funcional, Pilates e Personal Trainer |
| Planos | `Html/planos.html` | Planos mensal, trimestral, semestral e anual |
| Estrutura | `Html/estrutura.html` | Espaço da academia, professores, horários das aulas e funcionamento, aparelhos |
| Matrícula | `Html/matricula.html` | Formulário com dados pessoais, plano, modalidade principal, turno e objetivo |

## Tecnologias

- HTML5
- CSS3 (fonte Montserrat via Google Fonts)
- Layout responsivo com media queries

## Estrutura do projeto

```
fitcode-academia/
├── Html/    páginas do site
├── Css/     Style.css (estilo compartilhado por todas as páginas)
├── fotos/   imagens e ícone do site
└── README.md
```

## Como executar

Não precisa instalar nada. Baixe o projeto e abra `Html/index.html` no navegador. A navegação entre as páginas usa o menu no topo.
