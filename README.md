# ARENAFIT ACADEMIA

Projeto da disciplina **Design para Web II**: site institucional da academia **ArenaFit**, feito com HTML, CSS e JavaScript.

## Páginas

| Página | Arquivo | O que tem |
|---|---|---|
| Início | `Html/index.html` | Apresentação da academia, promoção, vantagens e depoimentos de alunos |
| Modalidades | `Html/modalidades.html` | Musculação, funcional, pilates e personal |
| Planos | `Html/planos.html` | Tabela com os planos e valores |
| Estrutura | `Html/estrutura.html` | Fotos da academia e professores |
| Matrícula | `Html/matricula.html` | Formulário de matrícula com validações em JavaScript |

## Estrutura de pastas

```
fitcode-academia/
├── Html/                  páginas do site
├── Css/Style.css          estilos de todas as páginas
├── JavaScript_Completo/   script.js (formulário) e LEIA-ME.txt
├── fotos/                 imagens usadas no site
└── README.md
```

## JavaScript (página de matrícula)

- Máscara de telefone com DDD e de CPF
- Validação dos dígitos verificadores do CPF
- Bloqueio de data de nascimento futura
- Mensagem de confirmação ao enviar

A confirmação é apenas demonstrativa: nenhum dado é salvo ou enviado.

## Como abrir

Baixe ou clone o repositório e abra o arquivo `Html/index.html` no navegador. Não precisa instalar nada.

## Tecnologias

HTML5, CSS3 (variáveis, flexbox, grid e media queries) e JavaScript puro.
